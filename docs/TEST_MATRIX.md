# Functional test matrix

This matrix maps product actions and important combinations to automated evidence. Real-browser
store QA remains necessary because YouTube and browser UI cannot be fully represented by jsdom.

| Area              | Cases covered                                                                                                                                          | Automated evidence                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| A/B selection     | Set from playback time, numeric input, ±0.1 adjustment, empty input, invalid and too-short ranges, duration overflow                                   | `loop-engine-complete`, `panel.integration`, `controller.integration`                                |
| Loop playback     | Activate, stop, jump at B, time-update fallback, frame callback, animation-frame fallback, cancellation and stale callbacks                            | `loop-engine`, `loop-engine-complete`, `controller.integration`                                      |
| Speed and pitch   | Clamp 0.25×–4×, reject non-finite values, propagate external YouTube rate changes, block changes during ads, always preserve pitch                     | `loop-engine-complete`, `controller.integration`, `popup.integration`                                |
| Advertisements    | Block seek/rate mutation, show spinner state, hide sharing controls, restore settings after the ad                                                     | `loop-engine`, `panel.integration`, `controller.integration`                                         |
| Widget            | Initial collapse, automatic first-point expansion, manual expand/collapse, dismiss, restore, replace, destroy and status feedback                      | `panel-collapse`, `panel.integration`, `controller.integration`                                      |
| Shortcuts         | Option/Alt+Shift+A/B/L, repeat rejection, unrelated key rejection and input-field isolation                                                            | `panel.integration`, `controller.integration`                                                        |
| Saving            | Autogenerated name, reviewed custom name, root/folder destination, duplicate prevention and saved badge                                                | `bookmarks`, `popup.integration`, `controller.integration`                                           |
| Updating          | Rename, A/B/rate edit, clamp, invalid rejection, duplicate rejection, quick update and cosmetic-name independence                                      | `bookmarks`, `popup.integration`, `controller.integration`                                           |
| Detaching         | Unlink a saved loop without deletion and prevent accidental reattachment/duplication                                                                   | `controller.integration`                                                                             |
| Library folders   | Root and nested creation, blank/cancel flows, collapse/expand, deletion and safe child/bookmark reparenting                                            | `bookmarks`, `popup.integration`                                                                     |
| Drag and drop     | Threshold activation, valid root drop, cancellation and irrelevant pointer gestures                                                                    | `popup.integration`                                                                                  |
| Opening fragments | Canonical tab URL, seek to A, bookmark selection, automatic activation and play rejection fallback                                                     | `bookmarks`, `popup.integration`, `controller.integration`                                           |
| Shared links      | Query/fragment parsing, Base64URL round trip, malformed/oversized/foreign payload rejection, YouTube ID match, range validation and clipboard fallback | `loop-links`, `early-capture`, `platform.integration`, `popup.integration`, `controller.integration` |
| Storage           | V1/V2/V3 migration, split-slice precedence, rename/playback race, ordered concurrent writes, no-op writes, quota/read failure and 250-loop bound       | `storage-slices`, `storage.complete`                                                                 |
| YouTube lifecycle | Watch-page discovery, missing DOM, SPA events, debounce, mutation discovery, navigation detach and controller teardown                                 | `youtube`, `youtube.integration`, `controller.integration`                                           |
| Localization      | English/Spanish key and placeholder parity, browser translation, fallback strings and localized attributes                                             | `locales`, `platform.integration`                                                                    |
| Accessibility     | Popup semantics and shadow-DOM widget checked with axe-core; keyboard isolation and labels exercised                                                   | `accessibility`, `panel.integration`                                                                 |
| Packaging         | Manifest parity, least permissions, browser-specific constraints, real PNG dimensions and all three validators                                         | `manifests`, `lint:extension`                                                                        |
| Performance       | Minified production builds, per-entry/package budgets and loop/codec/1,000-bookmark stress limits                                                      | `size`, `perf`                                                                                       |

## Manual release smoke test

For each browser, load a clean profile and verify: a fresh video starts collapsed; A/B/L shortcuts
work; typing does not trigger YouTube shortcuts; an ad swaps controls for the spinner; saving,
renaming, updating, detaching, dragging and deleting survive a restart; a shared link opens and
activates; SPA navigation leaves one widget; fullscreen/theater mode stays usable; and no unexpected
console error appears.
